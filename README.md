## 📦 EasyBorrow — Sistem Peminjaman Barang Berbasis Web

EasyBorrow adalah aplikasi web yang dirancang untuk membantu pengelolaan proses peminjaman dan pengembalian barang secara terstruktur dan terdokumentasi.
Sistem ini mempermudah admin maupun pengguna dalam melakukan pencatatan inventaris, pengajuan peminjaman, serta monitoring status barang secara real-time.

Aplikasi dibangun menggunakan Laravel Framework dengan arsitektur CRUD yang terintegrasi database sehingga meminimalkan kesalahan pencatatan manual dan meningkatkan efisiensi administrasi.

## 🎯 Tujuan Sistem

- Menggantikan pencatatan manual peminjaman barang
- Mempermudah monitoring stok dan status barang
- Mencatat riwayat peminjaman secara otomatis
- Meningkatkan akurasi data inventaris

## 🚀 Fitur Utama
-✅ Manajemen data barang (tambah, edit, hapus)
-✅ Pengajuan peminjaman barang oleh pengguna
-✅ Persetujuan / penolakan peminjaman oleh admin
-✅ Pengembalian barang dan update status otomatis
-✅ Monitoring stok barang tersedia / dipinjam
-✅ Riwayat peminjaman terdokumentasi
-✅ Sistem autentikasi login pengguna & admin
-✅ Dashboard informasi peminjaman

## 🧠 Teknologi yang Digunakan

| Layer | Teknologi |
|------|------|
| Framework | Laravel |

## 🗂 Struktur Sistem

Sistem memiliki dua role utama:

👤 User
- Melihat daftar barang
- Mengajukan peminjaman
- Melihat status peminjaman
- Melakukan pengembalian barang

🛠 Admin
- Mengelola data barang
- Mengelola data user
- Menyetujui atau menolak peminjaman
- Mengelola pengembalian
- Melihat laporan peminjaman
